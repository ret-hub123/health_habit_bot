# health_habit
This is an educational project to create a bot that monitors your health habits. 🥦

## Установка и настройка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv .venv`
3. Активируйте: `source .venv/bin/activate` (Linux/Mac) или `.venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Скопируйте `.env.example` в `.env` и заполните своими данными
6. Запустите: `flask run`
